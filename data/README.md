# Airport Operations Datasets

## Synthetic Dataset Disclosure
All sample datasets generated in `data/sample/` (`flights.csv`, `gates.csv`, `weather.csv`) are **synthetically generated with physical-statistical grounding** for portfolio demonstration and research. They are **not** real-world proprietary airport records.

## Dataset Structure
* `data/sample/flights.csv`: Flight schedules with airlines, aircraft types, terminals, runways, and taxi metrics.
* `data/sample/gates.csv`: Airport gates across Terminals 1, 2, and 3 with supported aircraft types.
* `data/sample/weather.csv`: Weather telemetry (temperature, wind speed, visibility, precipitation, condition).
